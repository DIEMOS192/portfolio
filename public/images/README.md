# Images Directory

Place your portfolio images here:

- `profile.jpg` - Your profile/headshot image
- `project-1.jpg` - Project screenshots
- `project-2.jpg` - Project screenshots
- `hero-bg.jpg` - Hero section background
- `about-bg.jpg` - About section background

Recommended image formats: JPG, PNG, WebP
Recommended sizes:

- Profile image: 400x400px
- Project images: 600x400px
- Background images: 1920x1080px
